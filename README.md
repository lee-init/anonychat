# anonychat
anonymous chat room application

## Description
A chat room application to learn Network Programming and C. Would like to route this through Tor for anonymity but that's simply wishfull 

This differs from Ripple as Ripple is a network scanner which requires raw packet sockets (I need the UNIX Networking C vol 1 book for that)

## Build

gcc anonychat.c

### Specify output file
gcc anonychat.c -o 


### Build with debugging
gcc -g -Wall -Wextra anonychat.c
